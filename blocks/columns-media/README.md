# columns-media

Custom **columns** block. Purpose: two fixed columns pairing a heading and text with a video, photo, icon list or embedded form.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: [heading + text | media]; a media cell holding only a YouTube/Vimeo/.mp4 link becomes an embedded player, only a /fragments/ link loads that fragment (e.g. a form), only an image is shown full width; paragraphs that start with a small icon image render as icon + text items.
