# cards-benefit-tiles

Custom **cards** block. Purpose: Row of tall rounded benefit tiles with a background photo, a title and a + button that reveals the benefit detail.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: optional image cell (tile background), then a cell with the tile title (heading) followed by optional detail content revealed by the + button; detail may be a single link to a /fragments/ page, which is loaded as a fragment.
