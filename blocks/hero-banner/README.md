# hero-banner

Custom **hero** block. Purpose: full-width background photo or illustration with an overlaid eyebrow, heading, text and CTA (optionally a foreground cut-out image).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: cell 1 = background picture; cell 2 = eyebrow paragraph, optional heading, text, CTA links (bold = primary, italic = secondary); optional further picture-only cell = foreground image.

## Supported variations

| Variation | Option class |
| --- | --- |
| Alt | `alt` |
| Image Only | `image-only` |
| Dark | `dark` |
| Alt 2 | `alt-2` |
