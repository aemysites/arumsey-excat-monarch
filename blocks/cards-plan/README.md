# cards-plan

Custom **cards** block. Purpose: cover tier cards with a coloured header bar.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: header cell (optional icon, title, badge) | body cell (text, lists, horizontal rules, links). With one cell, content up to and including the first heading (plus a short badge paragraph) becomes the header.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Light | `image-light` |
| Image | `image` |
| Light | `light` |
