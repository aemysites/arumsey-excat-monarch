# location-selector

Custom **custom** block. Purpose: Location context bar ("Products & pricing based on your address | Change") with an inline ZIP code form; lead-form option renders a "have us call you" lead capture form.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Default: row 1 = message | change trigger (text or link) | optional help; optional key/value rows ZIP label, Update label, Cancel label, Storage key. lead-form: intro row (headings/text), field rows Label | type (text, tel, email, number, zip, textarea, select) | name | placeholder [| select options], consent/disclosure text rows, submit row Label | submit, optional key/value rows Action (endpoint URL), Success, Error.
