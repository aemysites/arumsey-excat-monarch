# hero-page

Custom **hero** block. Purpose: inner-page title hero: either a full-bleed background photo with the page title over it (optionally with a text intro strip beneath), or a split layout with the photo beside a dark title/CTA panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = image (optional); row 2 = heading (h1 for page titles), optional subtitle/description and optional CTA link; optional row 3 = intro strip text (shown in a band beneath the photo). Image and content may also share one row as two cells. Default and split options render the split layout; image-dark, dark and intro-strip* options render the overlay layout.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Dark | `image-dark` |
| Intro Strip | `intro-strip` |
| Intro Strip Stacked | `intro-strip-stacked` |
| Dark | `dark` |
| Split | `split` |
| Intro Strip Cyan Dark | `intro-strip-cyan-dark` |
| Intro Strip Stacked Cyan Dark | `intro-strip-stacked-cyan-dark` |
| Split Cyan | `split-cyan` |
