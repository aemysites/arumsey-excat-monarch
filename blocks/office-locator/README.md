# office-locator

Custom **custom** block. Purpose: tax office details (eyebrow, address heading, map-linked address, opening hours, phone) beside a map and rating.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: cell 1 = eyebrow paragraph, heading, address paragraph linking to Google Maps, optional hours label paragraph + list of daily hours, phone paragraph with tel: link; cell 2 = Google Maps link (rendered as lazy embedded map) or a static map picture (image option), then rating text.
