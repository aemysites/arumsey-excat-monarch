# cards-highlight

Custom **cards** block. Purpose: Highlight tiles led by a large stat or key word (3x, 5%, Earn) with a label and supporting text; also used for rewards-rate strips, image cards and icon link rows.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: optional image/icon cell, then a body cell whose first heading (or fully bold first paragraph) is the stat, followed by label and text paragraphs or lists; a body holding only one link makes the whole tile clickable.
