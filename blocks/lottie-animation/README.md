# lottie-animation

Custom **custom** block. Purpose: standalone Lottie animation (e.g. animated card strip or scrolling ribbon) lazily rendered from a Lottie JSON file.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell: link to the Lottie .json file (link text or title = accessible label); optional fallback picture shown until/if the animation fails to load.
