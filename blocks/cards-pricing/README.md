# cards-pricing

Custom **cards** block. Purpose: pricing plan cards: optional tab label, tier heading, short description, feature list (bullet or icon items), price group pinned to the bottom, and primary button plus secondary link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per plan card; optional first cell = short tab label shown above the card (plain text, one paragraph or one heading such as the source `h4` eyebrow; a " + ..." add-on or bold/italic text in it is shown in neon); main cell = optional eyebrow link, heading, description, list of features, "Starting at" label, price (e.g. $0), fee notes, button(s) and links.
