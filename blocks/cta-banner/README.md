# cta-banner

Custom **custom** block. Purpose: horizontal call-to-action panel: short heading or copy on the left, one or two CTAs on the right, optionally with a product image and/or a full-bleed background image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row with only a background image; then one row with cells for an optional image, the copy (heading and/or text) and the CTA links. A cell holding only a link to a /fragments/ page is replaced by that fragment. Background colour comes from the section style (dark, blue, grey, light-blue), not from the block.
