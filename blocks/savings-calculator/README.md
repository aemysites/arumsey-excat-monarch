# savings-calculator

Custom **custom** block. Purpose: S Corp self-employment tax savings calculator with result panel and CTA panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Rows keyed in the first cell: Intro | heading + description; Field | label | help text (optional) | key (optional: net-income, salary, w2-income, w2-ss-withheld, other-se-income; defaults by order); Button | Calculate; Result | result heading | disclaimer; CTA | heading, text, link; Wage base | 184500 (optional, default 184500). Unkeyed rows fall back to intro, field, then CTA.

No variations.
