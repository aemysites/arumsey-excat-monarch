# hero-resource

Custom **hero** block. Purpose: resource-centre page hero: intro column (breadcrumb, heading, text, CTAs, share links) beside an aside of section links, a featured article card, a featured article list or an illustration.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: cell 1 = breadcrumb links paragraph, heading, text, CTA links, "Share:" paragraph with social icon links; cell 2 = aside (default: heading + list of icon links; featured-article: picture + icon + linked title; illustration: picture). featured-list: one extra row per article (picture | category + linked title) or a list in cell 2.

## Supported variations

| Variation | Option class |
| --- | --- |
| Featured Article | `featured-article` |
| Featured List | `featured-list` |
| Illustration | `illustration` |
| Featured Article 2 | `featured-article-2` |
