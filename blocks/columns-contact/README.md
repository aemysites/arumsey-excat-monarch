# columns-contact

Custom **columns** block. Purpose: contact / how-to-apply panel: columns of heading, icon-led help lines, phone numbers and links.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; one cell per column. Each cell: heading, then icon-led lines (icon + subheading), text, phone link and arrow links. A cell holding only a /fragments/ link is replaced by the fragment. with-select: a list of links in a cell becomes a dropdown (a list item without a link is the placeholder); a button straight after the list opens the chosen link.
