# reviews-list

Custom **custom** block. Purpose: authored replacement for a third-party reviews widget: overall rating, star distribution and individual reviews.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: summary rows (heading/text, score cell such as "4.3", review-count link); distribution rows [5 stars] [1110]; review rows [rating number] [title heading, author/date, review text] [details (optional)]. A cell holding only a /fragments/ link loads that fragment.

## Supported variations

No variations.
