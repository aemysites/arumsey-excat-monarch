# tabs-pill

Custom **tabs** block. Purpose: Pill-style tab switcher whose panels hold rich content.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tab: cell 1 = tab label, cell 2 = panel content. Because blocks cannot nest, a panel whose only content is a link to a fragment (/fragments/...) is replaced with that fragment (cards, columns, pricing, other blocks).

## Supported variations

No variations.
