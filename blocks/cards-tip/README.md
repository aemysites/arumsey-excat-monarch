# cards-tip

Custom **cards** block. Purpose: Tip callout boxes: small lightbulb icon beside a short tip, with optional nested links below, plus an optional trailing link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: icon cell | tip text cell; trailing link-only paragraphs or a link list in the text cell become the box's link list. A final row containing only a link (no icon) renders below the grid as a footer link.

## Supported variations

No variations.
