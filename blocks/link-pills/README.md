# link-pills

Custom block (no library base). Purpose: wrapping row of rounded pill links, e.g. an industries list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per pill with a link (or one cell holding a bulleted list of links); text without a link renders as a non-linked pill.

## Supported variations

No variations.
