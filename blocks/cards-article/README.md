# cards-article

Custom **cards** block. Purpose: teaser cards linking to guide/article pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: optional image cell | body cell (optional icon image, short eyebrow tag paragraph, heading, text, link/button paragraphs).
