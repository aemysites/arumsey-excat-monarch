# cards-article

Custom **cards** block. Purpose: Article/resource teaser grid: image, category eyebrow and linked title, with optional summary and button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image cell (optional) | body cell with optional category paragraph before the heading (eyebrow), the article title as a heading (usually linked), optional summary text and an optional final button paragraph (pinned to the card bottom). A card without a heading uses its link as the title (country-grid).

## Supported variations

| Variation | Option class |
| --- | --- |
| Country Grid | `country-grid` |
| With Button | `with-button` |
| Image | `image` |
| With Button 2 | `with-button-2` |
| Green Light | `green-light` |
