# cards-article

Custom **cards** block. Purpose: article and insight teaser cards (photo, optional tag, date, title, summary, Read more) linking to detail pages, optionally under a titled photo banner.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: cell 1 image (optional), cell 2 optional short tag text (e.g. Performance), last cell body with date paragraph, heading with link, summary and a Read more link paragraph. With photo-banner or photo-banner-boxed, an optional first row with a single cell holds the banner photo, an h2 title and a View all link.

## Supported variations

| Variation | Option class |
| --- | --- |
| Photo Banner | `photo-banner` |
| Photo Banner Boxed | `photo-banner-boxed` |
| Photo Banner Light | `photo-banner-light` |
| Overlay | `overlay` |
