# hero-video

Custom **hero** block. Purpose: full-bleed muted looping background video with overlaid eyebrow, title (text or image) and CTAs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: cell 1 = link to an .mp4/.webm video plus optional poster picture; cell 2 = eyebrow, heading or title image, CTA links.
