# tabs-panel

Custom **tabs** block. Purpose: tab strip over a bordered panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: tab label | panel content (rich text, or a link to a /fragments/ path to load blocks such as accordions).

## Supported variations

| Variation | Option class |
| --- | --- |
| Alt | `alt` |
| Steps | `steps` |
| Tiles | `tiles` |
| Shadow | `shadow` |
