# brand-bar

Custom **custom** block. Purpose: Thin family-of-brands strip with right-aligned logo links (H&R Block, Block Advisors, Spruce), the current brand highlighted.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with one cell per brand (or one cell with a paragraph per brand); each brand is a link wrapping a logo image/icon (or plain link text). Mark the current brand with `(active)` in its text or by bolding it; a same-origin link to `/` is also treated as current.

## Supported variations

No variations.
