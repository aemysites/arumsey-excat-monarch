# benefits-showcase

Custom **custom** block. Purpose: lifestyle image with an overlaid panel listing card benefits (heading plus benefit titles and descriptions).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image rows (picture only): first is the background, second is the side or decorative photo; first text row: panel heading; further rows: one benefit each (optional icon cell | title and description).

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |
| Benefit Columns | `benefit-columns` |
| Single Benefit | `single-benefit` |
| With Side Photo | `with-side-photo` |
