# cards-product

Custom **cards** block. Purpose: product cards with icon badge, offer, checklist and quote buttons.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card (cells merged): leading icon image, optional tag paragraph, heading, offer/text, tick list or icon list (items starting with an icon), link/button paragraphs.

## Supported variations

| Variation | Option class |
| --- | --- |
| Shadow | `shadow` |
| Light | `light` |
| Grey Light | `grey-light` |
| Compare | `compare` |
