# cards-product

Custom **cards** block. Purpose: product/offer cards with a photo (cut-out, side, full-bleed, small, or video still), linked heading, price line, description, check list and bottom-pinned button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = image (optional), cell 2 = heading (may be a link), optional price line, text, list, button(s). For `video`, include a link to the video in the body cell.

## Supported variations

| Variation | Option class |
| --- | --- |
| Photo Side | `photo-side` |
| Image | `image` |
| Video | `video` |
| Article | `article` |
| Checklist | `checklist` |
| Checklist Green Image | `checklist-green-image` |
