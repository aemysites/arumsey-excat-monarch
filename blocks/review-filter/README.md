# review-filter

Custom **custom** block. Purpose: Two dependent dropdowns (review type, then product) with a submit button that navigates to the chosen reviews page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional keyed rows: Type label | placeholder; Filter label | placeholder; Submit | button label. Every other row is one review type: type name (text or link) | list of product links.
