# columns-panel

Custom **columns** block. Purpose: dark boxed band of columns: intro beside link list, case study beside image, client video beside text, or a row of testimonials.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two or more cells; each cell holds text, a list of links (rendered as arrowed rows), an image, or a lone YouTube/Vimeo link (rendered as an embedded player). With testimonials each cell is: quote-icon image, quote paragraph, attribution paragraph.
