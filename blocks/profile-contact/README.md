# profile-contact

Custom block (no library base). Purpose: Contact strip on a person profile page: office address and LinkedIn link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per contact item (or one cell holding a bulleted list): office address linked to the office page, LinkedIn (or other social) URL, optional tel: phone and mailto: email links. Items are typed by link (linkedin/twitter/facebook/instagram/phone/email, otherwise address); bare social URLs become icon links with an aria-label.

## Supported variations

No variations.
