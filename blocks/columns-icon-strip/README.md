# columns-icon-strip

Custom **columns** block. Purpose: horizontal strip: a title on the left and a row of icon + eyebrow + link items.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; first cell is the strip title (heading or text), each further cell an item: icon, eyebrow text, link title, optional body text. with-body-text: items carry a heading and paragraph.

## Supported variations

| Variation | Option class |
| --- | --- |
| Light | `light` |
| With Body Text | `with-body-text` |
