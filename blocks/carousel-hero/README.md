# carousel-hero

Custom **carousel** block. Purpose: full-bleed rotating homepage hero: each slide shows a background image with date, headline, summary and CTA, with a row of story tabs (slide titles), prev/next and pause/play controls.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = background image; cell 2 = date/eyebrow paragraph, heading (h1/h2, also used as the tab label), description paragraph and a CTA link. Missing image or extra cells are tolerated.

## Supported variations

No variations.
