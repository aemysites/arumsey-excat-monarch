# legal-disclosures

Custom **custom** block. Purpose: page-bottom legal and trademark disclosures in small print, with an optional brand logo on the left and social icon links on the right.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; cells for an optional logo (image only), the disclosure copy (paragraphs with inline links), and an optional set of icon links (social media). A cell holding only a /fragments/ link is replaced by that fragment, so shared disclosures can be authored once.

No variations.
