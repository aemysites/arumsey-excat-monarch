# article-list

Custom **cards** block. Purpose: article listing fed by the site page index (/query-index.json).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: no authored cards; optional key/value rows: index (default /query-index.json), path (folder to list; default the current page folder, then its parent), template, limit (page size; 6 hub / 4 latest), title (latest heading), see all (link for the latest list).

| --- | --- |
| Latest | `latest` |
