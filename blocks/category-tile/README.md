# category-tile

Custom **custom** block. Purpose: banner-like link tiles with an uppercase label and an icon.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cells: label (heading or link) and background image. An optional second image is shown as the icon at the right.

The tile colour follows the citi.com card sequence by position among consecutive category-tile blocks in a section: 1st #034c81, 2nd #056dae, 3rd and later #008fc9. The background image is blended over it (`mix-blend-mode: overlay`).

## Supported variations

No variations.
