# disclosure-links

Custom **custom** block. Purpose: inline row of footnoted disclosure links (e.g. '1 Important Pricing & Information +') that jump to or expand legal disclosure content.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: first cell: the disclosure link (an optional superscript footnote number before it); optional second cell: the disclosure content, which the link then toggles open. A link to a /fragments/ page becomes a toggle that loads the fragment; a #hash link scrolls to and opens the matching details element.
