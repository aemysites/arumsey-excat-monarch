# cards-icon

Custom **cards** block. Purpose: Row of small icon + label items: feature strips, product quick links, category tab navigation and cross-sell link lists.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item: optional icon/image cell, then a cell with the label (often a link) and optional supporting text; an item with a single link is fully clickable.

## Supported variations

| Variation | Option class |
| --- | --- |
| Icon Beside Label | `icon-beside-label` |
| Quick Nav | `quick-nav` |
| Alt | `alt` |
| Grid | `grid` |
| Blue | `blue` |
| Card Cross Sell | `card-cross-sell` |
