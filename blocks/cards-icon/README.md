# cards-icon

Custom **cards** block. Purpose: Icon-led feature list: bare centred icons with optional heading, text and link, plus split media|text panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: icon or image cell | body cell with optional heading, text and links/buttons. Icon-only rows (no body) are allowed. In the split options (featured-offer, light-2, light-3, dark) the first cell is a photo and the second the text panel.

## Supported variations

| Variation | Option class |
| --- | --- |
| Light | `light` |
| Featured Offer | `featured-offer` |
| Light 2 | `light-2` |
| Dark | `dark` |
| Icon Left | `icon-left` |
| Light 3 | `light-3` |
| Dividers | `dividers` |
