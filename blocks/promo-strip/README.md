# promo-strip

Custom **custom** block. Purpose: Horizontal promotional strip: icon or image, heading, short text and a link or button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row; cells in order: icon/image (optional) | heading (or bold text) | text (optional) | link or button (optional). Cells are classified by content so any may be omitted.

## Supported variations

| Variation | Option class |

| Alt | `alt` |
| Dark | `dark` |
| Yellow | `yellow` |
