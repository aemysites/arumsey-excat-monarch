# columns-sidebar

Custom **columns** block. Purpose: wide body text column beside a narrow sidebar of promo cards or media.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: [body text, headings, lists | sidebar]; in the sidebar each image starts a promo card (image, heading, text, final link as CTA); a lone YouTube/Vimeo link becomes an embedded player.
