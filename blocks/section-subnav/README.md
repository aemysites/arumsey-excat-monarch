# section-subnav

Custom **custom** block. Purpose: in-page sub-section laid out as side-by-side columns: headed copy and bullet lists (What You Get / How It Works), a badge or photo beside copy, a centred CTA row, or centred icon columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one or more rows; each cell in a row is a column. A picture-only cell is a media column; any other cell is a text column (heading, text, lists, links), and a leading picture or icon paragraph in it is the column icon. A cell holding only a link to a /fragments/ page is replaced by that fragment. Colour comes from the section style (dark, blue), not from the block.
