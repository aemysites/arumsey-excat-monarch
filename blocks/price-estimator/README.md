# price-estimator

Custom **custom** block. Purpose: Toggle the tax situations that apply and see an estimated starting price.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Config rows keyed in the first cell: Prompt | question text; Result | result heading; Price | base price (e.g. $99); Note | price note (e.g. + additional state fee). Every other row is one situation: label | starting price when selected (optional) | CTA link (optional). Displayed price = highest of base and selected prices.
