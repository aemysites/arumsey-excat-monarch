# columns-footer

Custom **columns** block. Purpose: In-page legal/disclaimer columns placed above the site footer, plus a social-icon link row.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with 2 cells; each cell holds uppercase section labels followed by disclaimer paragraphs with inline links. With `social`, a single cell holds a list (or run) of icon links to social profiles.

## Supported variations

| Variation | Option class |
| --- | --- |
| Social | `social` |

N/A (Document Authoring project)
