# columns-icon-list

Custom **columns** block. Purpose: intro text column beside a vertical list of icon items (icon followed by short text).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 = intro heading/text, cell 2 = icon items, either a bullet list whose items start with an icon, or paragraphs each starting with an icon followed by text.
