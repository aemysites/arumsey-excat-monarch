# newsletter-signup

Custom **custom** block. Purpose: e-mail newsletter sign-up form: one e-mail field and a submit button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell (or rows): optional heading/intro text; paragraph with the field placeholder (trailing * = required); link whose text is the button label and href the POST endpoint; optional paragraph after the link = success message, next = error message.
