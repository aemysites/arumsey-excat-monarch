# legal-links

Custom **custom** block. Purpose: single row of uppercase legal/corporate links (Terms & Conditions, Privacy, Security, Careers, About us, Contact us) with a brand/home link (CITI.COM) on the left.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: first cell holds the brand or home link (text, logo or heading); further cells (or a list) hold the legal links. Any non-link copy, such as a copyright line, is kept below the links.

No variations.
