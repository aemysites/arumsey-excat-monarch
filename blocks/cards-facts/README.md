# cards-facts

Custom **cards** block. Purpose: grid of key company facts, each a bold label over an icon and a short value.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per fact: cell 1 label (e.g. Head Office:), cell 2 value text, optionally preceded by an icon (:icon-name: or a small image), either inline or in its own cell before the value.
