# software-download

Custom **custom** block. Purpose: Software update/download panel: copy with eyebrow, a version or state picker and a download button, optional image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row; cells by content: copy (eyebrow, heading, text) | list of versions/states (linked items are downloadable, plain items disable the button; optional paragraphs after the list give the price and button label) | image (optional).

## Supported variations

| Variation | Option class |
| --- | --- |
| With Image 2 | `with-image-2` |
| With Image | `with-image` |
| Product | `product` |
| Green | `green` |
