# carousel-cards

Custom **carousel** block. Purpose: a carousel of cards with prev/next buttons and slide indicators.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cells: optional image (or icon) and content (eyebrow, heading, text, link/button). A cell holding only a /fragments/ link is replaced by the fragment.

A paragraph holding only a plain link becomes the card's text CTA (blue link with chevron). Arrows and indicators move a full view at a time (3 cards on desktop by default) and wrap around.
