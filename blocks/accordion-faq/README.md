# accordion-faq

Custom **accordion** block. Purpose: Expandable FAQ list of questions and answers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per question: cell 1 = question text (author it as a heading, normally `h3`; the heading is kept inside the `<summary>`), cell 2 = answer (text, lists, links, buttons). An optional single-cell row before the first question is kept as an intro.

## Supported variations

| Variation | Option class |
| --- | --- |
| Light | `light` |
| Light 2 | `light-2` |
