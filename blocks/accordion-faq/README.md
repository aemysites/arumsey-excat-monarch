# accordion-faq

Custom **accordion** block. Purpose: collapsible FAQ list where each question row expands to reveal its answer.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per FAQ item; cell 1 = question (heading or text), cell 2 = answer (rich text); a row with only a question renders as a non-expandable item.

No variations.
