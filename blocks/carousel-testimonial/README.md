# carousel-testimonial

Custom **carousel** block. Purpose: testimonial slider: optional intro heading beside a carousel of quote cards (author name/role, optional photo, quote) with prev/next arrows and dot indicators.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row with a single cell containing the intro heading/text; then one row per testimonial: cell 1 = author (optional photo, name, role), cell 2 = quote. A single-cell row is a quote only. One testimonial renders without controls.
