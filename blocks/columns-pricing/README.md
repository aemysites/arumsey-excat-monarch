# columns-pricing

Custom **columns** block. Purpose: pricing explanation and price table beside a highlighted content panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: two cells [heading + intro text | panel heading + text + list]; rows 2+: the pricing table, one row per table row with one cell per column, the first of these rows being the column headers. The table is rendered under the intro text.
