# cards-people

Custom **cards** block. Purpose: grid of people (portrait, name with credentials, role, phone/email contacts and a Read More profile link).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per person: cell 1 portrait image, cell 2 body with a heading (name and credentials), a role paragraph, phone (tel:) and email (mailto:) links as a list or paragraphs, optional bio text and a Read More / Contact link paragraph.
