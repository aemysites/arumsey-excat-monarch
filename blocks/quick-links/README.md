# quick-links

Custom **custom** block. Purpose: bar of quick task or category links, optionally led by a label such as "I want to:".

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: a list of links or one link per row/cell; with the label option, the first row (heading or text) is the label.
