# officer-finder

Custom **custom** block. Purpose: Search for a home lending officer by location or last name.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Mode rows Label | placeholder | query parameter (e.g. Search by location | Location | location). Optional key/value rows: Endpoint (JSON search URL), Results page (URL to navigate to with the query), Button, No results, Error.
