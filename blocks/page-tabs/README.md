# page-tabs

Custom **custom** block. Purpose: Tabs that switch between sibling pages (link tabs) or between in-page panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tab: Label | optional panel. A label that is a link with no panel navigates to that page and is active on the matching path. A panel cell that holds only a same-site link (e.g. /fragments/...) is loaded as a fragment so it can contain other blocks; any other panel content renders inline.

## Supported variations

No variations.
