# glossary

Custom **custom** block. Purpose: searchable A-Z glossary: intro card (title, disclaimer, sub heading, search field) over a background image, a vertical letter tab list, and term/definition rows for the selected letter.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row with only a background image; single-cell rows before the terms are the intro (title, disclaimer, sub heading); then one row per term with the term in the first cell and the definition in the second (a single cell starting with a bold 'Term:' also works). Optional key/value rows: Search (search field label), No results (empty-state text). Single-cell rows after the terms are appended below (a /fragments/ link is loaded in place). Letter tabs are generated from the terms. The colon after each term is added by the block, so an authored trailing colon is optional.
