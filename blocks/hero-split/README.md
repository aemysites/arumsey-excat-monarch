# hero-split

Custom **hero** block. Purpose: product / service hero: text column (eyebrow, heading, text, optional price block or link selector, CTAs) beside a framed photo or Lottie animation.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: cell 1 = eyebrow/heading, text, optional list of links (rendered as a select + go button; a following CTA labels the button), CTA links; cell 2 = picture, or a link to a Lottie .json file. pricing: price paragraphs (or a list for side-by-side prices) between heading and CTAs; struck-through text = old price.
