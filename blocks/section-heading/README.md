# section-heading

Custom **custom** block. Purpose: section title bar: a large heading on the left with a 'View all' style link or button on the right, underlined by a rule; or a coloured text panel beside a photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: a heading cell (heading and optional text) and an optional link cell; a single cell whose trailing paragraphs are only links also works. promo-panel: a text cell (heading, text, optional CTA) and a picture-only cell; cell order sets the image side. A cell holding only a link to a /fragments/ page is replaced by that fragment. Panel colour comes from the section style, not from the block.
