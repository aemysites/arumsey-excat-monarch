# columns-divided

Custom **columns** block. Purpose: equal columns of heading + bulleted list or text, separated by vertical rules.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; one cell per column. Each cell: optional heading, list or text, optional link. four-columns lays the row out as four columns on desktop.

## Supported variations

| Variation | Option class |
| --- | --- |
| Four Columns | `four-columns` |
