# carousel-gallery

Custom **carousel** block. Purpose: event photo gallery: a sliding row of photos (3 per view on desktop) with prev/next arrows and page dots; clicking a photo opens it enlarged in a lightbox.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per photo; cell 1 = image; optional cell 2 = caption text. Rows without an image or text are dropped; with one page of photos the arrows and dots are hidden.

## Supported variations

No variations.
