# cards-checklist

Custom **cards** block. Purpose: columns of tick-icon list items (covered events, useful links).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: each cell is a column: optional image, optional heading/intro, and a bulleted list; a cell without a list is a full-width note/footnote. List items that start with an icon (e.g. :cross:) keep that icon instead of the default tick.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image | `image` |
| Image Alt | `image-alt` |
| Light | `light` |
