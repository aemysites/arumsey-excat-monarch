# cards-office-services

Custom **cards** block. Purpose: Office location services list: intro heading, grid of icon + service title + description, and a closing CTA button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row: intro heading (single cell). Service rows: icon cell | body cell with the service title (heading or bold paragraph) and description. Optional last row: CTA link/button only. A heading-only row after service rows starts a new group.
