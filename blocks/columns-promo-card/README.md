# columns-promo-card

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells inside a contained rounded card: image cell and text cell (optional eyebrow paragraph, heading, copy, price and CTA buttons, footnote).
