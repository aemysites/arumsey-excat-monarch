# refinance-calculator

Custom **custom** block. Purpose: Interactive cash-out refinance calculator.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Key/value rows (value = default, optional third cell = help text): Home value, Mortgage balance, Cash-out amount, Loan terms (comma list, e.g. 30-Year Fixed, 15-Year Fixed), Interest rate, LTV (default 80), Minimum cash-out (default 15000), Closing cost (% of loan, default 2), Button, Result title. Non-key rows before the first key row render above the calculator, rows after render under the form.
