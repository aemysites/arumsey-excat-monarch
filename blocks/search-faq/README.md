# search-faq

Custom **search** block. Purpose: FAQ search box with heading that filters FAQ items on the page or searches a query index.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: content rows (heading, intro); config rows [source] [query-index link, optional], [label], [placeholder], [button], [no results] [message], [limit] [10]. Without source it filters details / .accordion-item / .faq-item elements in main.
