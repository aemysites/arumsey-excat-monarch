# article-synopsis

Custom block (no library base). Purpose: insight article synopsis panel with read time, clamped summary text with a Read more toggle, and author bylines beside it.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: [title, e.g. Synopsis] [read time, e.g. 5 Minute Read]; row 2: summary text; optional row: Read more (turns into the expand toggle); then one row per author: [headshot image] [name (linked to profile) + role].

No variations.
