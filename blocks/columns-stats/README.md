# columns-stats

Custom **columns** block. Purpose: stats layout: a feature panel (photo + large figure such as "20 million+" and caption) beside a column of illustrated stat items.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 = one photo plus figure text (heading or bold paragraph starting with a number) and caption; cell 2 = items each starting with an icon/illustration followed by figure and caption text.
