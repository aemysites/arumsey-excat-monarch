# product-reviews

Custom **custom** block. Purpose: Customer review summary with rating snapshot, average category ratings, filter/sort and a paged review list with company responses.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional heading row (one cell with a heading). Keyed rows: Summary | overall rating | count text | list of "5 stars: N"; Ratings | list of "Category: 4.5"; Page size | 8; Load more | button label. Review rows: rating number | review content (title, author, date, body, Pros:/Cons: lines, recommend line) | list of "Category: 5.0" sub-ratings | company response (optional).
