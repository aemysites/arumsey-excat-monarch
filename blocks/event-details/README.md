# event-details

Custom block (no library base). Purpose: details panel with a title and meta line (event date/time or read time), clamped description with a Read more toggle, and optional presenter headshots.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: [title, e.g. Synopsis or Event details] [meta, e.g. date/time or 6 Minute Read]; row 2: description text; optional row: Read more (becomes the expand toggle); optional rows, one per presenter: [headshot image] [name (link) + role].

## Supported variations

No variations.
