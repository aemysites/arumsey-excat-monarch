# results-toolbar

Custom **custom** block. Purpose: Toolbar above a listing: result count, sort select and reset-filters link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row: result count text (e.g. 29 results) | list of sort options (linked items navigate; plain items set ?sort= and fire results-toolbar:sort) | reset link (e.g. Reset Filters). Any cell may be omitted.

## Supported variations

No variations.
