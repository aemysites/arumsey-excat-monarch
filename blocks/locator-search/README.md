# locator-search

Custom **custom** block. Purpose: postcode/suburb locator search (e.g. find a repairer) that submits to an authored URL.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: content rows (heading, intro); config rows [action] [URL], [param] [query name, default q], [label], [placeholder], [button], [states] [comma list -> state select], [state param] [default state], [new window] [yes]. Submits a GET to `action`.

No variations.
