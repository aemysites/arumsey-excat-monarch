# columns-profile

Custom **columns** block. Purpose: person profile: portrait, name/title/contact details and a biography in fixed columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row with one cell holding a heading; then one row per person with three cells [portrait image | name heading, job title, phone and email links list, Read more link | biography paragraphs]; the portrait or biography cell may be omitted.

## Supported variations

No variations.
