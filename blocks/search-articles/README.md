# search-articles

Custom **search** block. Purpose: Search field for resource-center articles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Rows (all optional): a text row with the field label/placeholder; a link to the results page (the form submits there with ?q=); a link to a .json query index (default /query-index.json). Without a results-page link, or on the results page itself, matching articles render inline.

## Supported variations

No variations.
