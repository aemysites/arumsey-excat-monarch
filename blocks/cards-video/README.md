# cards-video

Custom **cards** block. Purpose: look-alike items each with a heading (name or episode), role, description, optional link and an embedded video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item: cell 1 body with heading, optional bold role paragraph, description and optional link (e.g. Contact Kyla); cell 2 video link (YouTube or Vimeo URL, or .mp4), optionally with a poster image. With a poster the video loads on click; without, it loads lazily when scrolled into view.

## Supported variations

No variations.
