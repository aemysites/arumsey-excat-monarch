# tag-label

Custom **custom** block. Purpose: small category/status chips or a short labelled callout.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: each cell is one item: a short text or link becomes a chip; a cell with a heading or several paragraphs becomes a callout panel.
