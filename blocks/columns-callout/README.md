# columns-callout

Custom **columns** block. Purpose: two-column layout where the last text column is a tinted callout panel (optional heading, intro, check list, divider, footnote); the other column holds text or an image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 = text or image (with-image), cell 2 = callout panel content (heading, paragraph, bullet list rendered as check list, optional horizontal rule and footnote).

| --- | --- |
| With Image | `with-image` |
