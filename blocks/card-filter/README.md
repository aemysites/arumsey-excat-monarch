# card-filter

Custom **custom** block. Purpose: Dropdown select (e.g. "All Cards") that filters the card groups or comparison tables that follow it on the page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per dropdown option: cell 1 = option label (the first row is the "show all" option, e.g. All Cards), optional cell 2 = filter value. Filtered groups are the blocks after the filter in the same section, matched by their caption or heading text, or sections with a Filter section-metadata value.

## Supported variations

No variations.
