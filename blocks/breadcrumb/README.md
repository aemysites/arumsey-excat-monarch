# breadcrumb

Custom **custom** block. Purpose: Breadcrumb trail of ancestor pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One cell (or one row per crumb) with the trail in order: a list of links, or links in a paragraph. Plain text without a link is the current page; the last item is marked as current.

## Supported variations

No variations.
