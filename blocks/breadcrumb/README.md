# breadcrumb

Custom block (no library base). Purpose: breadcrumb trail of parent page links ending in the current page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per crumb with a link (or one cell holding a list of links); the last crumb is the current page and may be plain text; leave the block empty to build the trail from the URL path.

## Supported variations

No variations.
