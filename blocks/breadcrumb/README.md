# breadcrumb

Custom **custom** block. Purpose: breadcrumb trail from home to the current page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell holding a list of links (home first); last item may be plain text for the current page. Leave empty to derive the trail from the URL path and the page H1.

## Supported variations

No variations.
