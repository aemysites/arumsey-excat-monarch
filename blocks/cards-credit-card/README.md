# cards-credit-card

Custom **cards** block. Purpose: Credit card product tiles: optional offer badge strip, card art with annual fee caption, card name and description, icon feature list or offer box, Card details / Apply now CTAs and footnote links.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per product: optional first cell with a short badge text (e.g. Bonus Offer), a cell with the card art image and optional caption (annual fee), then a content cell with the card name heading, description paragraph, feature lists, link-only paragraphs for CTAs (Card details, Apply now) and footnote links.
