# cards-service

Custom **cards** block. Purpose: grid of service or topic tiles (optional icon, heading, short description, Learn more link) linking to detail pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: optional first cell with an icon (:icon: or small SVG image) or photo, then a body cell with heading (often linked), description and an optional link paragraph (Learn more / View All); an icon may also be the first paragraph of the body.
